# Workspace Style Guidelines & Customizations

- **Currency Display**: Always show monetary values in Indian Rupees (₹).
- Use `₹` for any absolute amounts (e.g., ₹10,000 P&L).
- Keep percentage metrics (`EV %`, `Max DD %`, `Win Rate %`, `Profit Factor`) as primary performance metrics.
- **Git Push Rule**: Only push code to GitHub when the user explicitly requests it (e.g. "push on git"). Never run `git push` automatically.
